# Adversarial Friends 0.2.0 Dogfood Execution Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Exercise the published `adversarial-friends==0.2.0` package through a bounded report, orchestrated crossexam, gate, and loop ladder, then produce an evidence-backed reliability report without changing runtime code.

**Architecture:** Run the installed `afriend` binary sequentially against one compact prior review so outputs are comparable. Each stage is a black-box checkpoint: capture the process exit and absolute run directory, validate the durable ledger/report/metadata, and continue only when the previous stage preserved an honest state. The crossexam stage deliberately halts for an empty, inspected orchestrator merge response so resume/replay behavior is exercised without inventing semantic merges.

**Tech Stack:** `afriend 0.2.0`, POSIX shell, `jq`, Git, Markdown, Codex unified terminal sessions.

state contradicts it.
