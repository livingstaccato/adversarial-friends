# Adversarial Friends 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce, publish, and locally install an internally consistent Adversarial Friends 0.3.0 release from the approved feature boundary plus the OpenCode Google credential repair.

**Architecture:** Work only in the isolated `codex/release-0.3.0` worktree until the reviewed release commit is ready. Treat canonical package assets as the source of truth, regenerate their plugin mirror and all PlantUML renders, then certify one immutable commit through repository, distribution, remote-publishing, and local-install verification.

**Tech Stack:** Python 3.11+, pytest, stdlib TOML/JSON, Ruff, mypy, uv/setuptools, PlantUML/Graphviz, GitHub Actions trusted publishing, PyPI, Codex personal plugins.

## 0.3.0

An authority-focused release that makes Adversarial Friends easier to invoke

  depth but remains policy-blocked unless explicitly granted for the run.

  by `opencode auth list`.

### Release assurance

- Hardened host-role, readiness, resume, workspace-asset, and report
  invariants; synchronized the packaged skill and Codex/Claude plugin payloads.
- Refreshed live documentation and architecture diagrams, with reproducible
  renders and complete distribution/install verification.
