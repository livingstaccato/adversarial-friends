## Ranked tool and harness defects

These are defects in adversarial-friends or its evidence contract. They are not conclusions about whether an individual review claim is correct.

### 1. High — natural loop-iteration exhaustion is not a ceiling

**Evidence.** Loop's `for range(max_loop_iterations)` ends naturally without assigning a ceiling. Run metadata derives `ceiling_hit` only from budget or cross-examination limits, and exit 11 is selected only when a ceiling string exists. Otherwise incomplete falls to exit 1, or a non-incomplete run can fall to exit 0. This dogfood run exhausted exactly two iterations with `dry_streak=0`, `ceiling_hit=null`, and exit 1. Evidence: `run-20260830T140332-b447186d/run.json`, the loop session at line 303, `src/adversarial_friends/commands/run.py:158-168,232-456`, `src/adversarial_friends/commands/runmeta.py:311-331`, and `src/adversarial_friends/commands/exits.py:58-61,99-107`.

**Reproduction.** Run loop with `--max-loop-iterations 2` against an input that produces new claims in both iterations; observe natural exhaustion with no `ceiling_hit` and no exit 11. The recorded dogfood run is that reproduction.

**Code inference.** If all dispatched friends succeeded and cross-examination were otherwise complete while the second iteration still introduced claims, `incomplete` could be false and this same fall-through could return exit 0 despite `dry_streak<2`. That path was not observed here; it follows from the cited exit ordering.

### 2. High — discovery and doctor call a model-less Ollama usable

**Evidence.** Ollama discovery tests endpoint reachability and creates a roster spec whose model is `None`; doctor counts every discovered result as usable. The transport refuses dispatch without a model. In all four runs, Ollama occupied one of four cap slots and failed every attempted round; OpenCode, which doctor also called usable, had already been dropped. Loop then disabled Ollama, removing the security lens, while a subsequent doctor still described all five as usable. Evidence: `src/adversarial_friends/roster.py:49-80,160-173`, `src/adversarial_friends/commands/doctor.py:49-72,103-130`, `src/adversarial_friends/http_transport.py:230-250`, every run's `run.json` and Ollama `*.err`, and `run-20260830T140332-b447186d/run.json`.

**Reproduction.** Make an Ollama endpoint reachable without configuring a model, run `afriend doctor`, then run with a friend cap that includes Ollama. Doctor reports it usable; dispatch records `cli 'ollama' requires an explicit model (no default exists); pass one in the roster` in `.err`/`run.json`, and a later roster entry may already have been dropped.

### 3. High/security — “OS-confined” omits authenticated connector authority

**Evidence.** The Codex adapter and generated sandbox describe local filesystem/process confinement. The actual profile permits `network*` and grants the entire `/Users/tim/.codex` subtree both read and read/write access. During observed calls, Codex used an already authenticated GitHub connector whose repository result exposed permission metadata including administrative/push authority; the run artifacts do not disclose this capability in their confinement summary. Every observed connector operation was read-only and fetched blobs matching the reviewed repository, so this report does **not** allege a mutation or exfiltration. Evidence: `src/adversarial_friends/assets/adapters/codex.toml:88-104`, `src/adversarial_friends/sandbox.py:21-73,234-302`, `run-20260830T140332-b447186d/round-2/codex-scope.sandbox:13,27,30`, and the connector calls recorded in `run-20260830T140332-b447186d/round-2/codex-scope.raw`.

**Reproduction.** Run Codex under the documented confined profile while Codex has a signed-in connector, then inspect the sandbox, raw transcript, and report disclosure. The denied `apply_patch` in `round-2/codex-scope.err` proves that local patch attempt was blocked; a clean worktree status immediately after loop proves only that no uncommitted local worktree or index change remained. It does not rule out commit, ref, or remote mutation. Neither fact reduces the connector's authenticated authority, which is not disabled or inventoried in `run.json`/report. Evidence: `run-20260830T140332-b447186d/round-2/codex-scope.err` and `/Users/tim/.codex/sessions/2026/08/30/rollout-2026-08-30T14-03-16-01a0547b-d32a-7323-9952-988846d25afb.jsonl:317`.
